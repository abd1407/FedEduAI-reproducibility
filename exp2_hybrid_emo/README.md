# Exp 2: Hybrid-Emo (facial expression and drowsiness channel)

**Status: available on request from the corresponding author.**

The Hybrid-Emo notebook (FER2013 facial-expression recognition with an OpenCV Haar cascade for face detection,
dlib's 68-point facial landmark predictor, a CLIP zero-shot boost for the expression classes, and eye-aspect-ratio
based drowsiness detection) is not included in this release. It is available from the corresponding author
(Abdullah Alsubhy) on reasonable request.

Data: FER2013 is public (Kaggle, "Challenges in Representation Learning: Facial Expression Recognition Challenge")
and is not redistributed here. The dlib landmark model `shape_predictor_68_face_landmarks.dat` is available from
http://dlib.net/files/.
