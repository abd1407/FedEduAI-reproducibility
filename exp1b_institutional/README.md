# Exp 1-B: institutional cohort (Flower + Opacus)

**The institutional data are not included.** Student-level academic records of the Islamic University of Madinah
are confidential; access requests go to the university's Data Management Office. This folder contains only code and
aggregate results (no student records, identifiers or model weights).

* `FedEduAI_Validation_v16.ipynb`: 5-round primary run `run_20260909_221120_v16_572abe60` (all arms trained from
  scratch, seeds 0-4; tables in the paper).
* `FedEduAI_Validation_v19.ipynb`: 50-round schedule sweep `run_20260910_190700_v19_c668991d`.
* `flower_app/`: the Flower 1.22.0 / Opacus 1.5.4 application generated by cell 8 of the v19 notebook
  (`fededuai_privacy_v19`): `pyproject.toml`, `fededuai_privacy/{task,server_app,client_app,local_grid}.py`,
  pilot scripts `start_server.sh`, `start_client.sh`, `provision_pilot.py`, `monitor_command.py`.
* `results/run_v16/`: `run_manifest_v16.json`, `paper_tables_v16.md`, `privacy_validation_primary_v16.json`,
  `privacy_validation_extended_v16.json`, `membership_lira_primary_v16.json`, `dp_budget_composition_v16.json`,
  `coverage_audit_v16.json`, `warning_target_audit_v16.json`, `artifact_inventory_v16.json`,
  `execution_source_audit_v16.json`, `remaining_evidence_v16.json`.
* `results/run_v19/`: `run_manifest_v19.json`, `schedule_sweep_v19.json`, `paper_tables_v19.md`,
  `dp_budget_composition_v19.json`, `coverage_audit_v19.json`, `warning_target_audit_v19.json`,
  `artifact_inventory_v19.json`, `execution_source_audit_v19.json`.

Primary settings (run manifest): 12 clients, 5 rounds, 1 local epoch, batch 64, SGD lr 0.05, clipping norm 1.0,
delta 1e-6, nominal epsilon 3 and 8, seeds 0-4; numpy 2.1.3, pandas 2.2.3, scikit-learn 1.6.1, torch 2.11.0,
flwr 1.22.0, opacus 1.5.4. The `paper_tables_*.md` files are written in Arabic by the notebook (table headers);
the numeric columns are the values reported in the paper.
